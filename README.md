# 📝 TO-DO List in JavaScript

Una splendida e minimale applicazione Web per la gestione dei task quotidiani. Questo progetto nasce con l'obiettivo di creare una lista di cose da fare fluida, accessibile e dal design moderno, sfruttando a pieno le potenzialità di JavaScript nativo e CSS Flexbox.

▶️ **[Guarda l'applicazione live su GitHub Pages](INSERISCI_IL_LINK_DELLA_TUA_PAGES_QUI)**

---

## 🚀 Funzionalità principali

* **Aggiunta rapida:** Inserisci i tuoi task cliccando sul pulsante dedicato o semplicemente premendo il tasto `Enter` (Invio).
* **Modifica in tempo reale:** Clicca sull'icona della matita (`✏️`) per modificare al volo il testo di un task senza alterare la struttura della lista.
* **Eliminazione immediata:** Rimuovi i task completati con un click sulla croce (`❌`).
* **Layout Responsivo:** Interfaccia fluida che si adatta a schermi desktop e mobile, con pulsanti di controllo perfettamente allineati a destra.

---

## 🛠️ Tecnologie Utilizzate

Il progetto è stato sviluppato interamente in modalità "Vanilla" (senza framework esterni):

* **HTML5:** Per la struttura semantica della pagina.
* **CSS3 (Flexbox):** Per un layout moderno, animazioni fluide sulle transizioni (`transition-duration`) e allineamento geometrico dei componenti.
* **JavaScript (ES6+):** Per la manipolazione dinamica del DOM, gestione degli eventi di tastiera/mouse e logica applicativa.
